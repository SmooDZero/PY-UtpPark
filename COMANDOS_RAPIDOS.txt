==========================================
  COMANDOS PARA EJECUTAR EL PROYECTO
==========================================

PASO 1: Instalar dependencias (SOLO PRIMERA VEZ)
--------------------------------------------------
npm install

PASO 2: Inicializar base de datos (SOLO PRIMERA VEZ)
-----------------------------------------------------
npm run init-db

PASO 3: Iniciar servidor (CADA VEZ QUE QUIERAS USARLO)
-------------------------------------------------------
npm start

Luego abre: http://localhost:3000
